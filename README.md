# Traffic Bridge

مرحله‌ی اول اپلیکیشن اندروید برای مدیریت اتصال ترافیک.

## وضعیت این مرحله

- رابط فارسی دو بخشی: «اتصال» و «شاد»
- دکمه‌ی اتصال با وضعیت قرمز/سبز
- نمایش آمار ارسال و دریافت
- باز کردن دامنه‌ی رسمی `https://web.shad.ir` در مرورگر دستگاه
- طراحی و وضعیت اتصال فعلاً محلی و نمایشی است

هسته‌ی واقعی VPN، احراز هویت سرور، ذخیره‌سازی نشست و مسیر انتقال ترافیک در
مراحل بعدی و پس از مشخص شدن معماری امن سرور اضافه می‌شوند. این نسخه اطلاعات
ورود شاد را داخل برنامه ذخیره نمی‌کند.

## اجرا

```bash
pnpm install
pnpm exec expo start
```

برای اجرای نسخه‌ی اندروید، پروژه را با Expo Go یا یک build اندرویدی باز کنید.

## نکات امنیتی

- هیچ توکن GitHub یا رمز عبوری در این مخزن قرار نمی‌گیرد.
- اعتبارنامه‌های افشاشده باید در سرویس مربوطه باطل و جایگزین شوند.
- قبل از فعال‌سازی هر نوع تونل واقعی، مدل تهدید، مدیریت کلید و محدودیت‌های
  سرویس مقصد باید جداگانه بررسی شوند.
